## 3. 从这些数字推出的复现标准

1. `Ours (no align)` 与 Table II 的 C_Concat 逐位相同 ⇒ **Table I / II 都不含 OT**；
2. 同一配置（α=0.3, λ=0.1）在 Table IV 是 `0.71` clean、在 Table V setting 2 是 `0.76`
   ⇒ 两表来自不同 run，**允许 ±0.05 的差**；
3. bucket 在 clean 上从 0.76 退化到 0.80，作者仍写 "slight improvement"
   ⇒ 只有 noisy 三档的改善是真实信号；
4. clean 的 run-to-run 波动是 0.054，所以"0.71 vs 0.89"是约 2.7σ（成立），
   而"0.80 vs 0.76"是 0.7σ（不成立）。

详见 `docs/zh_cn/replication_guide.md` §4.3 / §4.4。
